# Etappe Cycling wheelset configurator

A self-contained landing page and wheelset configurator. All HTML, CSS, and
JavaScript are embedded in `index.html`; open it directly in a modern browser
or serve it with any static web server.

The configurator updates its wheel-size and rim-profile choices for each
discipline, recalculates an indicative price, and downloads the selected setup
as a text file. It also offers a choice of Shimano Nexus 5, Shimano Alfine 11,
Rohloff SPEEDHUB 500/14, and enviolo Utility internal gear hubs. Hub compatibility
and any surcharge require a personal confirmation and are not included in the
indicative wheelset price. The gearing calculator provides discipline-specific
riding presets and calculates low/high gear speeds and cassette range from
cadence and wheel circumference. Prices and specifications are illustrative,
not a quotation; gearing speeds are theoretical estimates.
